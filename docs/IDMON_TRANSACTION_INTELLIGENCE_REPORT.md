# IDMON — Bitcoin Transaction Intelligence Report

A worked example showing how IDMON reconstructs stored historical and behavioural context around an observed Bitcoin transaction, compared with the information available from a conventional block explorer.

IDMON examines transaction structure, attribution, dormancy, historical address recurrence, route novelty, related activity and prior investigation context — while explicitly separating what the evidence supports from what remains unknown.

Research and intelligence only. Address linkage does not establish ownership, and Bitcoin movement or exchange deposits do not prove a sale occurred.
